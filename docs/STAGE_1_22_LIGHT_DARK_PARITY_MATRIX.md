# Stage 1.22 Light/Dark Parity Matrix

| Component | Shared geometry | Light value intent | Dark value intent |
|---|---|---|---|
| page shell | same content/sidebar offsets | airy ice mist with cyan/violet atmosphere | deep graphite glass with same atmosphere roles |
| panels | same radius/padding | translucent white material, low border | translucent graphite material, low ice border |
| `.cbi-value` rows | same label/field rhythm | quiet separators, no row cards | quiet separators, no row cards |
| fields | normal 38-40px, modal 36-38px, compact 30-34px | frosted field with graphite text | graphite field with ice text |
| buttons | same role geometry | neutral primary with cyan tint, no green | raised graphite/cyan primary, no neon |
| tabs | same pill language | soft inactive, elevated active | same shape, higher luminance active |
| dropdown | same popover radius/list density | white glass popover | graphite glass popover |
| dynlist | same compound rows | white compound field | graphite compound field |
| progress | same 16-18px meter | mist trough, restrained cyan fill | graphite trough, luminous cyan fill |
| sidebar | same row ownership | one rail, row state surface | one rail, row state surface |
| modal | same sheet geometry | translucent sheet | luminous graphite sheet |
| plugin pages | same page-scoped selectors | reduce plugin blue | reduce plugin blue/industrial dark |

Green/mint is semantic success only in both modes. Blue/cyan is atmosphere/focus/progress, not global plastic paint.
