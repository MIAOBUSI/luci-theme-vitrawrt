# Stage 1.21 Screenshot Diagnosis

Primary evidence source: `audit-output/visual-direction-1.20R/20260526-121703/`.

Stage 1.20R moved the theme closer to Apple/VisionOS in light mode, but the screenshots still show mint/aqua overuse and native LuCI residue in component internals. Stage 1.21 is a refinement pass: reduce green dominance, reduce visual weight, and finish safe CSS styling of internals without changing LuCI behavior.

## Stage 1.21 Audit Questions

1. Is green/mint still globally dominant?
2. Are primary actions and active tabs neutral/cyan rather than green?
3. Do progress bars read as VitraWrt meters, not native LuCI recolors?
4. Do dynlist existing items and add rows avoid native white patches?
5. Does cbi-dropdown open as a VitraWrt popover?
6. Are modal tabs free from rectangular strip residue?
7. Is sidebar hover one integrated row?
8. Are plugin pages visibly adapted without layout rewrites?
9. Are light and dark modes the same design system?
10. Did any LuCI behavior regress?
